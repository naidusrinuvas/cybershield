About CyberShield

CyberShield is a final-year cybersecurity assessment toolkit that combines password tools, encryption utilities, network scanning, website security checks, and vulnerability detection into a single Flask-based dashboard, with AI-generated plain-English explanations and a PDF report generator.

Note: All scanning and testing tools in this project are intended for use only against systems, networks, and websites you own or have explicit permission to test.
